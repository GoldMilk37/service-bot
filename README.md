# Service Bot（项目①：工具型 Agent）

手写 ReAct 循环 + Function Calling 的工具型 Agent，不依赖任何框架。

> 状态：🚧 W4 启动（2026-08-28），设计定稿 2026-09-05。本 README 随项目推进补全。

## 目标

毕业设计指导客服 Agent：用户用自然语言提问，Agent 自主决定调哪个工具、多轮调用、组织回答；搞不定时主动转人工。

- 亮点：工具错误容错、最大迭代次数保护、每一步 trace 打印、**转人工信号设计**
- 面试可讲：为什么合并重复工具（7→4）、什么时候不用工具（LLM 直答）、转人工的 6 类信号

## 技术栈

- Python + httpx（直调 DeepSeek function calling）
- 手写 Agent 循环（从 `03-practice/week04-react-loop/` 改造，不用 LangGraph，先懂本质）

## 场景与用户

**场景**：毕业设计指导——选题咨询、开题报告、任务书、进度规划、格式规范、查重降重、答辩准备、导师沟通。

**用户画像**：大四本科生，对流程不熟悉、时间紧迫、焦虑感强，问题集中在"不知道怎么做""不知道合不合格""来不及了怎么办"。

## 工具清单（定稿：5 个）

> 设计原则：职责清晰、数量精简。最初草稿有 7 个工具，其中 4 个本质都是"查政策库"
> （查重率/中期检查/格式/延期），已合并为一个 `query_policy(category)`——
> 工具越多、描述越像，模型选错的概率越高。

| 工具 | 参数 | 数据来源 | 说明 |
|------|------|---------|------|
| `query_policy` | `category`：查重/中期检查/格式规范/延期申请/答辩安排… | `policies.json` | 查学校政策规定（合并原 4 个查询工具） |
| `get_writing_guide` | `doc_type`：开题报告/任务书… | `guides/` Markdown 文档 | 各类文书的写作指南 |
| `get_timeline_template` | `deadline`（今天由工具自算） | 内置模板 + 日期计算 | 按剩余天数生成阶段规划 |
| `check_topic_feasibility` | `topic`、`major` | 规则判断（关键词+负面清单） | 选题可行性初筛 |
| `transfer_to_human` | `reason` | 无（打印转接话术并结束） | 触发转人工信号时调用 |

**参数注意**：日期不让模型传——模型不知道"今天"，工具内部 `datetime.now()` 自己算，模型只传 `deadline`。

## 10 个典型问题 → 处理方式

| # | 用户问题 | 处理方式 |
|---|---------|---------|
| 1 | 开题报告怎么写 | `get_writing_guide("开题报告")` |
| 2 | 我这个选题行不行 | `check_topic_feasibility(topic, major)` |
| 3 | 查重率要求多少/怎么降重 | `query_policy("查重")` + LLM 给降重建议 |
| 4 | 来不及了，帮我排时间规划 | `get_timeline_template(deadline)`（今天由工具自算） |
| 5 | 任务书和开题报告有什么区别 | **LLM 直接答（无工具）** |
| 6 | 中期检查要交什么 | `query_policy("中期检查")` |
| 7 | 论文格式有什么要求 | `query_policy("格式规范")` |
| 8 | 答辩 PPT 怎么做 | **LLM 直接答（无工具）** |
| 9 | 导师不回我消息怎么办 | **LLM 直接答（无工具）** |
| 10 | 我想申请延期答辩 | `query_policy("延期申请")` → 需人工审批 → `transfer_to_human` |

> 知道什么时候**不用**工具和会调工具一样重要：概念解释、经验建议类问题 LLM 直答更快。

## 转人工信号（6 类）

| 信号类型 | 触发条件 | 示例 | Agent 回复 |
|---------|---------|------|-----------|
| 涉及审批流程 | 需要学院/教务处人工审批 | "我要申请延期答辩" | "延期申请需要提交纸质材料到教务处，我帮您转接教务老师。" |
| 情绪崩溃/焦虑严重 | 极度焦虑、崩溃情绪 | "我真的做不完了，要崩溃了" | "我理解您的压力。我帮您转接学业辅导老师，他们可以给您更个性化的建议。" |
| 涉及学术不端 | 提到代写、买论文等 | "你能帮我写论文吗？" | "抱歉，我不能代写论文。建议您和导师沟通，我可以帮您梳理框架和思路。" |
| 学校特定政策 | 学院内部未公开的政策 | "我们学院有没有特殊加分政策？" | "这个涉及学院内部规定，我这边没有相关数据，建议您直接咨询教务老师。" |
| 用户明确要求 | 主动要求人工 | "转人工" | "好的，正在为您转接..." |
| 多轮无法解决 | 同一问题 3 轮以上仍未解决 | 反复问"还是不明白" | "这个问题可能和您的具体情况有关，建议转接人工详细沟通。" |

## 设计要点

- **多轮记忆**：messages 历史拼进每轮调用（chat-api 踩过"存了没喂回去"的坑：记忆三要素=存、取、用，缺一不可）；"3 轮无法解决"信号靠数同一问题的对话轮数实现
- **错误容错**：工具执行异常返回错误信息回填给模型，让它自己调整重试
- **安全边界**：学术不端拒答；转人工兜底——Agent 不假装能办自己办不了的事

## 演示剧本（面试黄金对话）

- **演示 A（多步工具）**：查重率问题 → `query_policy("查重")` → LLM 结合政策给降重建议
- **演示 B（工具+转人工）**：申请延期 → `query_policy("延期申请")` → 需审批 → `transfer_to_human("延期审批")`

## 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/GoldMilk37/service-bot.git
cd service-bot

# 2. 创建并激活虚拟环境（Python ≥ 3.10）
python -m venv .venv
.venv\Scripts\activate        # Windows；Mac/Linux: source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置 API Key
#    在项目根目录新建 .env 文件，写入一行：
#    DEEPSEEK_API_KEY=sk-你的key
#    （key 在 platform.deepseek.com 注册后创建）

# 5. 启动
python main.py
```

启动后进入命令行对话，试试这些问题：

| 你问 | Agent 会 |
|------|---------|
| 查重率要求多少 | 调 `query_policy("查重")` 查政策后作答 |
| 我要申请延期答辩 | 先查延期政策 → 发现需线下审批 → 调 `transfer_to_human` 转人工 |
| 开题报告怎么写 | 调 `get_writing_guide("开题报告")` 返回指南全文 |
| 帮我排个时间规划，6月10日答辩 | 调 `get_timeline_template` 按剩余天数生成四阶段计划 |
| 我这个选题行不行：基于深度学习的图像识别 | 调 `check_topic_feasibility` 规则初筛 |
| 我刚才问了啥 | 直接凭会话记忆回答（多轮记忆） |

输入 `q` 退出。
