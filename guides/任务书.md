# 任务书写作指南

> 数据来源：本指南为演示用假数据，内容参考通用高校要求编写。

## 任务书是干嘛的

任务书 = 导师下达给你的"任务委托单"，由**导师签发**（不是你写给导师的）。它和开题报告的区别：

| | 任务书 | 开题报告 |
|---|---|---|
| 谁写 | 导师起草、学生补充细节 | 学生写 |
| 篇幅 | 1-2 页 | 3-8 页 |
| 内容 | 要做什么、什么标准、什么时间交 | 为什么做、怎么做、研究基础 |
| 性质 | 合同/验收依据 | 立项论证 |

**顺序**：一般先定题目 → 签任务书 → 再写开题报告。

## 标准结构（4 部分）

### 1. 课题名称与来源
- 名称要具体：对象 + 方法 + 目的（"基于 ______ 的 ______ 系统/方法设计与实现"）
- 来源：结合导师科研项目 / 自拟 / 生产实际

### 2. 主要任务与目标（3-5 条）
- 用动词开头、可验收的写法：完成 ✅"设计并实现……模块，实现……功能"；不要写 ❌"学习……知识""了解……技术"
- 每条任务对应论文的一个交付物

### 3. 预期成果与考核标准
- 成果形式：毕业论文 + 系统原型/实验报告/数据集等
- 考核标准尽量量化：准确率/功能项数/字数

### 4. 进度安排
- 4-6 个里程碑节点即可，粒度到月/半月
- 必含节点：开题、中期检查、初稿、查重、答辩

## 常见问题

- **任务书和开题报告内容重复？** 正常，角度不同：任务书写"做什么"，开题报告写"为什么和怎么做"。两边进度安排要一致，别自相矛盾
- **题目中途要改？** 需要重新走任务书变更流程（导师签字 + 学院备案），答辩前 6 周截止
- **字数写满好还是简洁好？** 任务书贵在"边界清晰"，1-2 页说清楚即可，写太长反而验收时被抓把柄
