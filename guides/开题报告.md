# 开题报告写作指南

> 数据来源：本指南为演示用假数据，内容参考通用高校要求编写。

## 开题报告是干嘛的

开题报告 = 向导师和学院证明三件事：**这个问题值得研究、你懂怎么研究、你的计划做得完**。它是整个毕设的"立项书"。

## 标准结构（5 部分）

### 1. 选题背景与意义（约 500 字）
- 从大背景讲到小问题（漏斗式）：行业/领域现状 → 存在什么问题 → 本文聚焦哪个具体问题
- 意义分两层：理论意义 + 实际应用价值，各 1-2 句即可，不要拔高喊口号

### 2. 国内外研究现状（约 800-1500 字）
- 不是文献堆砌，要**有述有评**：按主题（不是按论文）分 2-3 条线梳理
- 每条线结尾加一句评价："上述工作主要针对 X 场景，对 Y 问题考虑不足"——这句话就是你研究的切入口
- 引用 15-30 篇，近 5 年文献占比 ≥ 50%，必须有 2-3 篇英文文献

### 3. 研究内容与技术路线（最核心）
- 研究内容 2-3 条，每条一句话 + 2-3 句展开
- 技术路线画**流程图**（推荐 draw.io）：数据/输入 → 处理方法 → 输出/验证
- 每条研究内容要能对应到论文的一个章节，别列做不到的

### 4. 进度安排
- 按周或按月列表格：时间段 / 任务 / 交付物
- 留 2 周缓冲（格式调整、查重、打印装订永远比想象慢）

### 5. 参考文献
- 按 GB/T 7714 格式，与正文引用一一对应

## 常见退回原因（自检清单）

- [ ] 题目太大（"基于深度学习的研究"——研究什么对象、解决什么问题？）
- [ ] 研究现状只列文献没有评述
- [ ] 研究内容和最终论文对不上
- [ ] 进度安排精确到"第 15 周完成论文"这种不可执行粒度
- [ ] 技术路线没有图

## 一句话模板（选题背景开头）

> "随着______的快速发展，______需求日益增长；然而现有______方法存在______问题；本文针对______，提出/设计/实现______，以达到______。"

填空完读三遍，删掉空话，就是合格的背景段。
